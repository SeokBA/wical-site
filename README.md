# WiCal 기존 주소 안내

공식 웹사이트: https://wical-c0e8c.web.app/

이 저장소는 기존 앱의 GitHub Pages 주소를 유지하기 위한 공개 안내 페이지만 포함합니다. 각 페이지는 Firebase Hosting의 해당 페이지로 연결됩니다. 자동 이동이 차단된 경우 직접 링크를 사용할 수 있습니다.

GitHub Pages 배포: `main` 브랜치의 `/docs`.

앱이나 웹사이트의 원본 소스 및 이전 Git 이력은 포함하지 않습니다. 기존 앱의 지원·개인정보 링크를 유지하기 위해 저장소 이름과 Pages 경로를 변경하지 않습니다.
