02 / BEFORE YOU WRITE

이렇게 알려주세요

사용 중인 iPhone 기종, iOS 버전, WiCal 버전과 문제가 발생한 순서를 알려주시면 확인에 도움이 됩니다.

화면을 첨부할 때는 일정 제목·연락처 등 개인 정보를 가려주세요.

자주 묻는 질문

일정이 보이지 않아요.

iPhone 설정에서 WiCal의 캘린더 권한이 전체 접근으로 허용되어 있는지 확인하세요. 쓰기 전용 접근으로는 일정을 불러올 수 없습니다. WiCal 설정에서 표시할 캘린더도 선택해 주세요.

iPhone의 기본 캘린더 앱에서도 일정이 보이지 않으면 먼저 기기의 캘린더 계정과 동기화 설정을 확인하세요.

일정을 추가하거나 수정할 수 없어요.

쓰기가 허용된 캘린더가 필요합니다. 구독 캘린더나 읽기 전용으로 공유받은 캘린더는 수정할 수 없습니다. iPhone 캘린더 앱에서 해당 캘린더에 일정을 추가할 수 있는지 확인한 후 WiCal에서 다시 시도해 주세요.

홈 화면 위젯은 어떻게 추가하나요?
  1. WiCal을 실행하고 캘린더 전체 접근을 허용합니다.
  2. 홈 화면의 빈 공간을 길게 누르고 위젯 추가 화면을 엽니다.
  3. WiCal을 검색하고 원하는 위젯과 크기를 선택합니다.
  4. 추가한 위젯을 길게 눌러 위젯 편집을 열면, 지원되는 위젯에서 표시할 캘린더를 선택할 수 있습니다.

위젯의 갱신 시점은 iOS가 관리합니다. 위젯이 바로 바뀌지 않으면 WiCal을 한 번 열어 권한과 캘린더 선택을 확인해 주세요.

위젯 두 개를 각각 다른 달로 볼 수 있나요?

위젯 편집에서 서로 다른 탐색 그룹을 선택하세요. 같은 종류·크기·그룹을 사용하는 위젯은 탐색 상태를 공유합니다. 기본 설정의 날짜를 누르면 앱에서 해당 날짜가 열립니다. 위젯 자체의 월 이동을 사용하려면 지원되는 월간 위젯에서 탐색 그룹을 선택하세요.

탐색 상태는 약 5분 후 만료되며, 다음 갱신 때 현재 날짜를 기준으로 표시됩니다. 다른 달을 영구 고정하는 기능은 아닙니다.

일정 알림이 오지 않아요.

WiCal 설정의 일정 알림을 켜고, iPhone 설정에서도 WiCal 알림을 허용해 주세요. 일정에 알람이 설정되어 있어야 합니다. 집중 모드와 알림 요약 설정도 확인해 주세요.

WiCal의 알림 설정과 기본 캘린더 앱의 알림 설정은 별개입니다. 같은 일정의 알림이 중복된다면 각 앱의 알림 설정을 확인하세요.

실시간 현황은 어떻게 사용하나요?

아직 끝나지 않은 일정의 상세 화면에서 실시간 현황 시작을 누르세요. 지원 기기의 잠금 화면과 Dynamic Island에서 일정을 확인할 수 있습니다. 기기에서 WiCal의 실시간 현황 사용이 허용되어 있어야 합니다.

일정 상세의 종료 버튼으로 끝낼 수 있습니다. 버튼이 보이지 않으면 일정 종료 시각과 기기 설정을 확인해 주세요.

검색에서 오래된 일정이 나오지 않아요.

WiCal 검색은 현재 날짜를 기준으로 과거 1년부터 미래 1년까지의 일정을 대상으로 합니다. 제목, 위치, 메모, 캘린더 이름으로 검색할 수 있습니다.

개인정보 설정을 바꾸거나 삭제를 요청하고 싶어요.

iPhone 설정에서 WiCal의 캘린더·알림·추적 권한을 변경할 수 있습니다. WiCal 설정에 광고 개인정보 옵션이 표시되면 광고 관련 선택을 다시 확인할 수 있습니다.
