적용 범위와 운영자

SeokHo Kim(이하 “운영자”)는 WiCal 앱 및 이 지원 웹사이트를 운영합니다. 개인정보 관련 문의와 요청은 seokho0330@gmail.com로 접수합니다.

WiCal은 자체 회원가입이나 로그인 없이 iPhone의 시스템 캘린더를 사용합니다. 이 방침은 WiCal의 데이터 처리에 적용되며, 사용자가 연결한 캘린더 계정과 외부 서비스에는 각 제공자의 정책도 적용됩니다.

캘린더와 기기 내 기능

사용자가 캘린더 전체 접근을 허용하면 일정의 제목, 날짜·시간·시간대, 위치, 메모, URL, 반복·알람 및 캘린더 정보를 읽어 표시합니다. 일정의 생성·수정·삭제는 선택한 시스템 캘린더에 반영됩니다. 계정 동기화와 캘린더 보관은 기기 및 해당 캘린더 서비스의 설정을 따릅니다.

선택한 캘린더 식별자, 주 시작일, 알림 설정, 위젯 탐색 상태 등은 기기에 저장하고 앱과 위젯 사이에서 공유합니다. 일정 알림은 기기에서 예약하며, 위젯과 실시간 현황에는 일정 제목·시간·위치 등이 표시될 수 있습니다. 잠금 화면의 노출 범위는 기기 설정에서도 관리할 수 있습니다.

일정을 공유하면 제목·시간·위치·메모 등 일정 내용이 사용자가 선택한 앱으로 전달됩니다.

지도와 위치 정보

위치가 입력된 일정의 상세 화면을 열면 해당 위치 문자열을 Apple 지오코딩 서비스로 보내 지도 표시용 좌표를 조회합니다. 지도 기능 사용 시 Apple 서비스가 관련 요청을 처리합니다.

자세한 내용은 Apple 개인정보처리방침을 참고하세요.

광고와 동의 설정

WiCal은 배너 광고 제공에 Google AdMob을, 광고 관련 개인정보 선택 관리에 Google User Messaging Platform(UMP)을 사용합니다. 광고 제공·측정·부정 사용 방지를 위해 IP 주소에 따른 대략적인 위치, 기기 또는 설치 식별자, 광고 노출·상호작용 및 진단 정보 등이 처리될 수 있습니다. 처리 범위는 동의 상태, 기기 설정 및 광고 서비스 구성에 따라 달라집니다.

앱은 광고 요청 전에 UMP 상태를 확인하고 필요한 경우 동의 화면을 표시합니다. iOS 추적 권한이 필요한 경우 별도로 요청합니다. 추적을 허용하지 않아도 광고 또는 오류 진단에 필요한 일부 정보 처리는 이루어질 수 있습니다.

설정에 “광고 개인정보 옵션”이 표시되는 경우 해당 항목에서 선택을 다시 확인할 수 있습니다. 자세한 정보는 Google 개인정보처리방침과 Google Mobile Ads 데이터 안내에서 확인할 수 있습니다.

오류 진단과 성능 정보

WiCal은 안정성과 성능 개선을 위해 Firebase Crashlytics와 Performance Monitoring을 사용합니다. 충돌 보고서, 성능 지표, 기기·앱 버전 정보, 설치 식별자, IP 주소와 이를 바탕으로 한 국가 정보 및 네트워크 성능 정보 등이 Google에 전송되어 처리됩니다. 이 진단 수집을 끄는 별도의 앱 내 설정은 현재 제공하지 않습니다.

Firebase Analytics의 이용 분석 수집은 비활성화되어 있습니다. 이는 위 광고·진단 서비스의 모든 데이터 처리가 중단된다는 의미는 아닙니다.

Google의 Firebase 안내에 따르면 Crashlytics의 충돌 스택과 관련 식별자는 90일 보관 후 삭제 절차를 시작합니다. Performance의 IP 연관 이벤트는 30일, 설치 연관 자료 및 비식별 성능 자료는 60일 후 삭제 절차를 시작합니다. 서비스별 자세한 항목과 보관 기준은 Firebase 개인정보 및 보안 안내를 참고하세요.

문의와 웹사이트 이용

이메일로 문의하면 회신 주소, 발신자명과 문의 내용 및 첨부 파일을 지원·개인정보 요청 처리와 후속 대응을 위해 사용합니다. 문의에는 필요한 정보만 포함하고 일정 제목이나 다른 사람의 연락처 등은 가려주세요.

문의 이메일과 첨부자료는 문의 처리와 후속 대응이 끝나면 삭제될 예정입니다.

이 웹사이트에는 자체 광고, 방문 분석 스크립트 또는 문의 입력 폼을 두지 않습니다. 사이트를 제공하는 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 사항은 GitHub 개인정보처리방침을 참고하세요. 이메일은 Gmail을 통해 수신·관리됩니다.

권한 변경과 데이터 삭제

  • 캘린더 접근: iPhone 설정에서 WiCal의 권한을 철회할 수 있습니다. 접근을 철회하면 일정 조회·관리 기능을 사용할 수 없습니다.
  • 알림과 실시간 현황: 기기 설정에서 허용 여부와 표시 범위를 변경할 수 있습니다. WiCal에서 일정 알림을 끄면 앱이 예약한 알림을 제거합니다. 이미 표시된 알림은 기기의 알림 센터에서 정리할 수 있습니다.
  • 광고 선택: iPhone의 추적 설정과, 표시되는 경우 WiCal의 광고 개인정보 옵션에서 변경할 수 있습니다.
  • 일정 삭제: WiCal 또는 시스템 캘린더 앱에서 해당 일정을 삭제하세요. 연결된 계정의 동기화 설정에 따라 다른 기기에도 삭제가 반영될 수 있습니다. WiCal을 삭제하는 것만으로 시스템 캘린더 일정이 삭제되지는 않습니다.
  • 앱·SDK 자료: 기기 설정, 백업 및 외부 서비스에 저장된 데이터는 서로 다른 보관 기준을 따릅니다. 앱 삭제가 모든 기기·서버 데이터의 즉시 삭제를 뜻하지 않습니다. 기기 백업은 iCloud 또는 컴퓨터의 백업 설정에서 별도로 관리하세요.
