Frequently asked questions

Why can’t I see my events?

In iPhone Settings, check that WiCal has Full Access to calendars. Write-only access cannot be used to read events. In WiCal Settings, select the calendars you want to display.

If events are also missing from the system Calendar app, check your device’s calendar account and sync settings first.

Why can’t I add or edit an event?

You need a writable calendar. Subscription calendars and calendars shared with read-only access cannot be edited. Check whether you can create an event in that calendar using the system Calendar app, then try again in WiCal.

How do I add a Home Screen widget?
  1. Open WiCal and allow full calendar access.
  2. Touch and hold an empty area of your Home Screen and open the widget gallery.
  3. Search for WiCal and choose a widget and size.
  4. Touch and hold the widget and choose Edit Widget. Supported widgets let you select which calendars to display.

iOS manages widget refresh timing. If a widget has not updated, open WiCal to check calendar access and your selected calendars.

Can two widgets show different months?

Choose different navigation groups in Edit Widget. Widgets of the same kind, size and group share their navigation state. With the default configuration, tapping a date opens it in the app. To navigate months within a supported monthly widget, select a navigation group.

Navigation state expires after about five minutes. At the next refresh, the widget returns to the current date. It does not permanently pin a different month.

Why am I not receiving event notifications?

Enable Event Notifications in WiCal Settings and allow notifications for WiCal in iPhone Settings. The event must have an alert set. Also check Focus and notification summary settings.

WiCal notifications and system Calendar notifications have separate settings. If you receive duplicate alerts for an event, check both apps’ notification settings.

How do I use Live Activities?

Open the details of an event that has not ended and tap Start Live Activity. It can appear on the Lock Screen and Dynamic Island on supported devices. Live Activities must be enabled for WiCal on your device.

Use the stop button in the event details to end it. If the start button is missing, check the event’s end time and your device settings.

Why are older events missing from search?

WiCal searches events from one year before to one year after the current date. You can search by title, location, notes or calendar name.

How can I change my privacy settings or request deletion?

Change calendar, notification and tracking permissions in iPhone Settings. If Ad Privacy Options appears in WiCal Settings, you can use it to review your advertising choices.

Deleting the app does not delete system calendar events. Read our privacy policy for information about data handling and deletion, or contact seokho0330@gmail.com.
